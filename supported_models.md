# GitHub Copilotでサポートされている AI モデル

GitHub Copilotでサポートされている AI モデルについて説明します。

GitHub Copilot は複数の AI モデルをサポートし、それぞれが異なる強みを持ちます。 速度とコスト効率に優先順位を付けるものもあれば、精度、推論、またはマルチモーダル入力用に最適化されているものもあります。 適切なモデルは、タスクによって異なります。 選択に役立つ side-by-side 比較については、 [AI モデルの比較](/ja/copilot/reference/ai-models/model-comparison) を参照してください。

使用できるモデルは、Copilotプランと、Copilotや IDE などのGitHub.comを使用している場所によって異なります。

> [!NOTE]
> モデルの利用可能性は変わる場合があります。 一部のモデルは、時間が経つと置き換えられたり更新されたりする可能性があります。

すべての既定の AI モデルでは、入力プロンプトと出力入力候補は、有害なコンテンツ、不快なコンテンツ、トピック外コンテンツ、および有効な場合のパブリック コード 照合のために、 GitHub Copilotのコンテンツ フィルターを通じて実行されます。

## 拡張機能を備えたモデル

最新の Copilot モデルでは、次の拡張機能がサポートされています。

* **100 万トークン コンテキスト ウィンドウ**: モデルが 1 つのセッションで大幅に多くのコンテンツを処理できるようにします。 これは、大規模なコードベース、長いドキュメント、または複雑なマルチファイル プロジェクトで作業する場合に便利です。 サポートされているモデルを選択すると、既定のコンテキスト サイズまたは拡張 (100 万トークン) コンテキストのどちらかを選択できます。
* **構成可能な推論レベル**: 応答を生成する前に、モデルの推論プロセスの深さを制御します。 サポートされているモデルを選択すると、使用する推論レベルを選択できます。 推論レベルが高いほど、複雑な問題に対する対応の品質が向上する可能性があります。

コンテキスト ウィンドウを大きくするか、より高い推論を選択すると、 AI credits 消費に影響します。トークンが多く消費されるため、使用されるクレジットが増えます。 このため、通常のコンテキスト ウィンドウと通常の推論を既定で使用し、より大きなコンテキスト ウィンドウを選択し、より複雑なタスクに対してのみより高い理由を選択することをお勧めします。

> [!NOTE]
>
> * 100 万トークン コンテキスト ウィンドウは、 Visual Studio Code および Copilot CLI でのみ使用できます。
> * 構成可能な推論レベルは、 Visual Studio Code、 Copilot CLI、および Copilot cloud agentで使用できます。
> * 一部のモデルには拡張機能の価格があり、[GitHub Copilot のモデルと価格設定](/ja/copilot/reference/copilot-billing/models-and-pricing#pricing-tables) を参照してください

詳細については、[フォールバック モデルと長期サポート モデル](/ja/copilot/reference/ai-models/fallback-and-lts-models)を参照してください。

## 評価モデル

モデル評価は、プロンプトと応答の品質を評価し、特定のユース ケースに最適なモデルを特定するのに役立ちます。 モデル評価では、 Copilotのプロンプトと入力候補の有効性を測定するために、専用の評価モデルが使用されます。

詳細については、「[GitHub Copilot での AI モデルの評価](/ja/copilot/concepts/ai-models/evaluating-models)」を参照してください。

評価機能では、次のモデルが使用されます。

* **GPT-5.4 mini**: 応答の正確性と関連性を評価するために使用されます。 効率性と速度のために最適化されています。
* **Claude Haiku 4.5**: コンテキストの理解と推論の品質を評価するために使用されます。 複雑なプロンプトの迅速な評価に適しています。

## ユーティリティ モデル

ユーティリティ モデルは、 Copilotの特定のバックグラウンド タスクと補助関数を処理する特殊なモデルです。 これらは、主要なコード生成とチャット機能と共にバックグラウンドで動作します。

Copilot では、次のユーティリティ モデルが使用されます。

* **MAI-Code-1.1-Flash**: コードのインデックス作成、コンテキストの取得、および軽量タスクに使用されます。 パフォーマンスを最適化するためにバックグラウンドで動作します。
* **GPT-5.4 nano**: 特殊なタスク用の軽量モデル。 最小限のオーバーヘッドを必要とする高速で単一目的の操作に使用されます。

[^mai-models]: MAI models are continuously improving models. Performance and behavior may evolve over time.

## 既定の有効化の対象となるモデル

一部のモデルは、 Copilot で既定で有効になっており、他のモデルでは管理者または個々の構成が必要になる場合があります。

詳細については、「[GitHub Copilotでの AI モデルへのアクセスの構成](/ja/copilot/how-tos/copilot-on-github/set-up-copilot/configure-access-to-ai-models)」を参照してください。

管理者は、組織または企業レベルでモデルの可用性を管理できます。 これにより、組織の標準と要件に合わせてモデル アクセスを制御できます。

## モデルサポート

AI モデルは継続的に開発されています。 新しいモデルが導入され、既存のモデルが更新され、古いモデルは段階的に廃止される可能性があります。 モデルの廃止と更新に関する最新情報については、[GitHub Changelog](https://github.blog/changelog) を参照してください。
