# Architecture Decision Records (ADR)

[English](README.md) | [日本語](README.ja.md)

An ADR records one architectural decision: context, options, decision, consequences. SDDs (`docs/specifications/`) describe how the system *is*; ADRs explain *why* it is that way. Write each ADR in English and Japanese (`NNNN-<slug>.md` / `NNNN-<slug>.ja.md`), number sequentially, and do not rewrite an accepted ADR — supersede it with a new one.
