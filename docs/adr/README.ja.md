# アーキテクチャ決定記録（ADR）

[English](README.md) | [日本語](README.ja.md)

ADR は 1 つのアーキテクチャ上の決定（背景・選択肢・決定・結果）を記録する。SDD（`docs/specifications/`）はシステムが「どうなっているか」を、ADR は「なぜそうなったか」を説明する。ADR は日英で書き（`NNNN-<slug>.md` / `NNNN-<slug>.ja.md`）、連番を振る。承認済みの ADR は書き換えず、新しい ADR で置き換える。
